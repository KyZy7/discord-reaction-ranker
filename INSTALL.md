# Install Discord Reaction Ranker

1. Download `discord-reaction-ranker-1.1.0.zip` from this project's GitHub Release assets. Choose this installation ZIP rather than GitHub's automatically generated source archives.
2. Extract the ZIP into a permanent folder. Do not select the ZIP itself or move/delete the folder after installation.
3. Open `edge://extensions` in Microsoft Edge or `chrome://extensions` in Google Chrome.
4. Enable **Developer mode** and select **Load unpacked**.
5. Choose the extracted folder containing `manifest.json`.
6. Reload existing Discord browser tabs, browse a forum at `https://discord.com`, and select **Reaction rankings** at the bottom right.

No build, bot, token, developer account, or server administrator access is needed. Works on the desktop Discord website, not the Discord desktop application.

## Updating

Download and extract the newer installation ZIP, replacing the files in your existing extension folder. Click **Reload** on the extension's card, then refresh Discord. Unpacked installations do not update automatically.

## Troubleshooting and removal

If collection stays empty, confirm the extension has site access to Discord, reload it and the Discord tab, and browse additional forum posts. Only responses Discord loads while you browse are captured; counts are last observed, not continuously live. Refreshing starts a fresh ranking collection.

Keep Developer mode enabled. Your browser may display a notice about unpacked extensions. To uninstall, select **Remove** on the extension card; this also removes saved forum-name metadata.
